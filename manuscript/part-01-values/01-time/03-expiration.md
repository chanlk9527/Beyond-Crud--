# 到期以后，系统到底该做什么

[第 1 章：时间不是一个 datetime](../01-time.md)

时间算对、存对以后，还需要让实际请求兑现这个边界。后台任务迟到、请求在途和操作尚未完成时，各自应该怎样处理？

<a id="sec-1-4"></a>

## 1.4 到期了，清理任务还没跑

<a id="sec-1-4-1"></a>

### 1.4.1 新请求由谁判断

一种常见实现是每天零点把过期会员的 `status` 改成 `EXPIRED`，授权接口只检查状态。现在让任务晚跑十分钟：数据库里的截止时间已经到了，状态却还没改。用户是否仍然可以使用？

如果答案是可以，任务实际决定了有效期。原本的业务承诺是零点失效，程序兑现的却是“等任务执行后失效”。

授权路径应当使用服务端提供的当前时间和 `expires_at` 判断，并结合暂停、撤销等其他条件。本例先假设服务端时钟满足业务需要；它为什么仍需检查来源和误差，会在后面的时钟部分展开。

![零点起授权拒绝新访问，后台批任务直到零点十分才更新状态](../../assets/ch01/10-expiry-and-cleanup.svg)

图 1-3：其他资格满足时，授权从零点起拒绝新请求；后台状态更新迟到十分钟，不增加十分钟权限。虚线对齐时刻，横向不按比例。

缓存一个 `is_valid = true` 也有同样的问题。到期前一分钟生成的结果，如果再缓存五分钟，就可能多放行四分钟。缓存截止值可以让读取方重新判断自然到期，但续期或撤销之后仍需传播数据变化。能算出时间边界，不代表已经处理了所有权限变化；这部分实现取舍放在 [权限与时钟实验](../../../examples/ch01-time/deep-dive.md#validity-and-clock-tests)。

<a id="sec-1-4-2"></a>

### 1.4.2 截止前点击，还是截止前受理

用户在截止前点击下载，请求在截止后才到达服务器。如果规则只写“截止前即可”，这个请求仍然没有明确答案。

我们为本例再作一个选择：以服务端受理检查时刻为准。客户端点击时间不充当授权证据。页面也应当对应这个承诺，不能写“截止前点击即可”，代码却按服务端执行受理检查的时刻判断。

对需要后续处理的申请，本例把检查时刻和获准结果可靠保存，保存失败不能返回受理成功。检查在截止前通过的申请，可以沿用这次资格继续完成，不必让后续每个阶段重新与当前时间比较。否则同一个申请可能入口获准、出口过期，用户仍然不知道究竟是否受理。

![甲在截止前点击但截止后到达而被拒绝，乙在截止前受理后可在截止后继续提交](../../assets/ch01/02-admission-cutoff.svg)

图 1-4：本例以服务端受理为准，并保存资格供后续处理沿用。点击早不等于已受理；截止前受理的申请可以继续提交。虚线对齐同一截止边界，横向不按比例。

换一种业务，可以选择在最终确认时重新检查资格，但这会改变用户获得的承诺。需要明确的是哪一步负责决定，以及后续能依据什么继续处理。

<a id="sec-1-4-3"></a>

### 1.4.3 已经开始的操作能否继续

用户在最后一秒开始下载，文件需要半小时才能下完。本例允许这个已获准的下载完成，到期后不允许重新发起。只在入口检查，就能对应这项继续规则。若业务要求到期立即中止，则需要在持续操作期间复核，并说明怎样执行中止。

宽限期也要单独命名。例如另一项产品选择“已有下载最多继续十分钟”，就同时存在新操作的截止和已有操作的继续上限。不能偷偷把 `expires_at` 加十分钟，否则新请求也可能获得这段时间，客服看到的日期却没有变化。

时钟误差容忍又是另一个决定。例如技术上允许两秒偏差，不等于产品赠送两秒会员；取消下载宽限，也不应顺手改变时钟容忍。把两者分别命名，才能分别判断依据和影响。

<a id="sec-1-4-4"></a>

### 1.4.4 访问结束以后，数据还要留多久

会员在零点失效，记录可能仍保留三十天供恢复，文件还可能有独立的导出窗口。权限截止、恢复窗口和允许删除的时间，可以分别命名为 `access_expires_at`、`recoverable_until`、`delete_after`。

这些名字让一次修改影响的承诺更容易看清。延长保留期不应该自动延长会员，修改会员有效期也不应该提前删除仍承诺保留的数据。数据库 TTL、清理队列和对象存储生命周期执行的是资源处理，授权应依据自己的规则。

回到同一个零点：新请求因为达到截止而被拒绝；已经受理的操作按本例约定继续；后台任务可以稍后整理状态和清理资源。分别给出这三个答案，“到期自动失效”才有了可以检查的含义。

到目前为止，最后有效日期都是明确给出的。产品如果改成“购买后七天有效”或“每月续费”，截止值就需要计算。接下来看看，这些话里的“天”和“月”究竟表示什么。
